# مقياس التفقيط العربي

مقياس مفتوح يختبر محرّكات تحويل المبالغ إلى حروف على **قواعد العدد والمعدود**.

🔗 **الصفحة:** https://opusstudiohq-max.github.io/arabic-invoice-mcp/tafgeet/

## المبدأ

**الحَكَم قاعدة نحوية مسمّاة، لا محرّكنا.** كل حالة في `cases.json` مرتبطة برقم
قاعدة (المثنى، جمع القلة، التمييز المنصوب، إسقاط النون بالإضافة، المنازل
العشرية بحسب العملة…). ومن يخالف حالةً فليخالف **القاعدة** — ونرحّب بذلك علناً
ونصحّح المقياس إن ثبت الخطأ.

**وحالات الخلاف النحوي مستبعَدة عمداً** (101، 102، 1001) — لا نُسقط محرّكاً على
صيغة لا نملك لها حكماً قاطعاً.

## المقياس عضّ صاحبه أولاً

قبل النشر شغّلنا **حزمتنا المنشورة على npm** على الحالات نفسها فوجدناها
**19/50 (38%)** — أفضل من أضعف محرّك في الجدول بـ16 نقطة فقط، ونحن على وشك
نشر مقياسٍ للصحّة. أُصلحت قبل النشر، وصارت 50/50.

ولذلك **يفرض اختبارُ الإصدار أن يجتاز كل محرّك نملكه** قبل أي نشر.

## إعادة التشغيل

```bash
git clone https://github.com/opusstudiohq-max/arabic-invoice-mcp
cd arabic-invoice-mcp/tafgeet
node run.mjs --fetch
```

- المحرّكات العامة تُجلب **مرة واحدة وتُخزَّن** في `cache/`، ولا يُكرَّر الطلب،
  وتُشغَّل محلياً في نطاق معزول.
- لفحص حزمة TypeScript أيضاً: `cd ../typescript-lib && npm i && npm run build`.
- المقارنة تتجاهل التشكيل وصيغ الألف والمسافات و«فقط… لا غير»، **ولا تتجاهل
  التنوين** لأنه موضع الخلاف نفسه.
