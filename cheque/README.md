# 🖋️ مُتوافِق — طباعة الشيكات بالتفقيط العربي الصحيح

أداة **مجانية ومفتوحة** تملأ الشيك وتطبعه، وتفقّط المبلغ بالعربية **تفقيطاً
صحيحاً نحوياً** — وهي المشكلة التي تخطئ فيها أغلب البرامج.

## جرّبها

- **نسخة الملف الواحد:** [`dist/mutawafiq-cheque.html`](dist/mutawafiq-cheque.html)
  — نزّلها وافتحها بنقرتين. بلا تثبيت، وبلا إنترنت، وبلا خادم.
- **نسخة التطوير:** `index.html` (تحتاج خادماً محلياً لأنها وحدات ES).

## لماذا التفقيط هنا مختلف

| المبلغ | الصواب | ما تكتبه أغلب البرامج |
|---|---|---|
| 2 ريال | **ريالان** | اثنان ريال |
| 3 ريال | **ثلاثة ريالات** | ثلاثة ريال |
| 11 ريال | **أحد عشر ريالاً** | أحد عشر ريال |
| 103 ريال | **مائة وثلاثة ريالات** | مائة وثلاثة ريالاً |
| 2000 جنيه | **ألفا جنيه** | ألفان جنيه |
| 0.750 دينار | **سبعمائة وخمسون فلساً** | خمسة وسبعون فلساً |

المحرّك منقول عن نسخة بايثون تحرسها **183 اختباراً**، و**اختبار تكافؤ يقارن
540 حالة** بين النسختين ويفشل عند أول اختلاف.

> نقلنا المحرّك أول مرة عن نسخة TypeScript فأنتج **215 اختلافاً من 540** —
> تلك النسخة تفتقد التذكير/التأنيث وإسقاط النون بالإضافة. اختبار التكافؤ هو
> ما كشفها قبل أن تُشحن.

## الخصوصية — بالبناء لا بالوعد

لا خادم، ولا شبكة، ولا تحليلات. افتح تبويب الشبكة في متصفحك أثناء الاستخدام
وسترى **صفر طلبات**. ويُحفظ محلياً **القالب فقط** — لا مبلغ ولا اسم مستفيد.
وصورة الشيك تُقرأ داخل المتصفح ولا تُرفع.

## المعايرة

مقاسات الشيكات تختلف بين بنك وآخر، لذلك **القوالب المدمجة نقاط بداية لا
مقاسات رسمية**. ارفع صورة شيكك، اسحب الحقول فوقها، واحفظ القالب باسمك.

## البناء والاختبار

```bash
node cheque-tool/build.mjs              # يولّد dist/mutawafiq-cheque.html
node cheque-tool/tests/parity.test.mjs  # 540 حالة تكافؤ مع بايثون
node cheque-tool/tests/build.test.mjs   # سلامة نسخة الملف الواحد
```
