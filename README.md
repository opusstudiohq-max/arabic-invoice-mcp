## ⚠️ النطاق — نقوله قبل أن تسأل

هذه الأدوات تفحص **بنية** البيانات فقط:

**✅ ما تفحصه:** اكتمال حقول QR للمرحلة الأولى (الوسوم 1-5) • صحة الرقم الضريبي (15 رقماً يبدأ بـ3) • صيغة الطابع الزمني ISO 8601 • حدود طول TLV (255 بايت).

**❌ ما لا تفحصه:** الوسوم التشفيرية للمرحلة الثانية (6-9: الهاش، توقيع ECDSA، المفتاح العام) • صحة ملف UBL XML وقواعد الأعمال • سلسلة هاش الفواتير • صلاحية شهادة النظام (CSID).

**🚫 والأهم:** **لا تستطيع هذه الأدوات — ولا أي أداة محلية — تأكيد أن الهيئة قبلت فاتورتك.** حالة القبول (clearance/reporting) تعيش في استجابة منصة «فاتورة» داخل نظام المنشأة، لا داخل الملف. هيئة الزكاة والضريبة والجمارك تنص على المعنى نفسه بخصوص أدواتها الرسمية.

**للتحقق الرسمي** استخدم أدوات الهيئة ومنصة فاتورة. هذه أدوات مساعدة للكشف المبكر عن الأخطاء الشائعة — لا بديل عنها.

*هذا مشروع مستقل غير تابع لهيئة الزكاة والضريبة والجمارك ولا معتمد منها.*

## 📦 المحتويات

```
checker/          أدوات الويب (JS خالص، بلا تبعيات، تعمل محلياً)
python-lib/       خادم MCP بايثون + المكتبة (176 اختباراً)
typescript-lib/   نسخة TypeScript من الأدوات الأساسية
eta-lib/          مكتبة الفاتورة الإلكترونية المصرية (ETA) — بايثون + TypeScript
tafgeet/          مقياس التفقيط العربي المفتوح
```

### `python-lib` — خادم MCP والمكتبة

أدوات جاهزة للاستخدام مع Claude Desktop / Claude Code / Cursor:
- **`tafgeet`** — تفقيط الأرقام إلى كلمات عربية صحيحة نحوياً (مفرد/مثنى/جمع، تذكير/تأنيث، إضافة ونصب) لـ8 عملات.
- **`zatca_qr`** — توليد رمز QR بترميز TLV/Base64 بحقول المرحلة الأولى.
- **`saudi_vat_pro`** — ضريبة القيمة المضافة لـ7 دول عربية، ضريبة انتقائية، وحسابات التأمينات.
- **`date_converter`** — تحويل هجري/ميلادي (أم القرى)، أيام العمل، المناسبات.

```bash
cd python-lib && pip install -e ".[dev]" && pytest -q     # 176 passed
```

### `eta-lib` — الفاتورة الإلكترونية المصرية (ETA)

التسلسل الكنسي والتجزئة والتحقق وبناء المستندات — **مُتحقَّق بايتاً ببايت
من العيّنة الرسمية** المنشورة على بوابة الهيئة.

**لماذا:** صفر حزمة npm لمنظومة ETA، والمرجع الرسمي `EInvoicingSigner`
مهجور منذ يناير 2024 بـ**63 نسخة مشتقة** — أي 63 فريقاً لم يجدوا بديلاً.

```bash
python -m pytest eta-lib/tests -q            # 50 passed
cd eta-lib/ts && npm test                    # نسخة TypeScript + تكافؤ مع بايثون
```

**ولا يشمل التوقيع والإرسال** — الهيئة لا تمنح حساب بيئة تجريبية لمطوّر
مستقل، ولن نشحن كوداً لم يُشغَّل على المنظومة الحقيقية.
