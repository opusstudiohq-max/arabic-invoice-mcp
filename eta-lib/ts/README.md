# eta-einvoice

**التسلسل الكنسي والتجزئة لمنظومة الفاتورة الإلكترونية المصرية (ETA)** —
مُتحقَّق **بايتاً ببايت** من العيّنة الرسمية المنشورة على بوابة الهيئة.

> Canonical serialization & SHA-256 hashing for the Egyptian Tax Authority
> (ETA) e-invoice system. Verified byte-for-byte against the authority's own
> published sample, and cross-checked against a Python reference implementation.

## الاستخدام

```js
import { loadDocument, serializeDocument, canonicalHash } from "eta-einvoice";

const doc = loadDocument(fs.readFileSync("invoice.json", "utf-8"));
console.log(serializeDocument(doc));       // النص الكنسي
console.log(await canonicalHash(doc));     // SHA-256 بحروف كبيرة
```

## ⚠️ الفخّ الذي يفرض محلّلاً خاصاً

مواصفة الهيئة تُلزم بأخذ القيمة **بشكلها اللفظي**: `0.0` تبقى `0.0` ولا تصير
`0` ولا `0.00`.

و`JSON.parse` **يُسقط هذا الفرق نهائياً**:

```js
JSON.parse('{"a":0.0}').a === JSON.parse('{"a":0.00}').a   // true — الأصل ضاع
```

فيختلف الهاش عن هاش الهيئة **ويُرفض المستند بلا تشخيص مفيد**.

ولذلك تحمل هذه الحزمة **محلّل JSON صغيراً** يحفظ نصّ كل رقم كما كُتب —
بلا اعتماد على `JSON.parse` ولا على ميزات Node حديثة.

```js
serializeDocument(loadDocument('{"a": 0.0}'))    // '"A""0.0"'
serializeDocument(loadDocument('{"a": 0.00}'))   // '"A""0.00"'   ← مختلف، وهذا صواب
```

**وكذلك:** ترتيب المفاتيح محفوظ لأنه جزء من الهاش، والمصفوفة المجرّدة تُرفض
لأن اسمها جزء من التسلسل.

## القواعد المُطبَّقة

من [مواصفة الهيئة](https://sdk.invoicing.eta.gov.eg/document-serialization-approach/):

1. معالجة **تعاودية** من جذر المستند
2. أسماء الخصائص إلى **حروف كبيرة**
3. القيم **بلا أي معالجة** — بشكلها اللفظي
4. الأسماء والقيم البسيطة بين علامتَي اقتباس
5. في JSON: بادئة باسم المصفوفة، **ثم اسمها قبل كل عنصر**

⚠️ **جذر المستند ليس جذر الإرسال** — مرّر مستنداً واحداً، لا مصفوفة `documents`.

## ما ليس هنا

**التوقيع `CAdES-BES` والإرسال.** الهيئة لا تمنح حساب بيئة تجريبية لمطوّر
مستقل، والختم الإلكتروني لا يرتبط إلا بكيان قانوني. **ولن نشحن كوداً لم
يُشغَّل على المنظومة الحقيقية ونقول إنه يعمل** — وهذا بالضبط ما ورّثه
المرجع المهجور لـ63 فريقاً.

النسخة الأشمل (مُحقِّق + بنّاء مستندات) بلغة بايثون في
[`eta-lib`](https://github.com/opusstudiohq-max/arabic-invoice-mcp/tree/main/eta-lib).
